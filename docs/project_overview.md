# Pulse9 Project Overview

## Project Purpose
Pulse9 is a Next.js/TypeScript application with Prisma ORM and authentication features. It is a forum/discussion platform with capabilities for creating, updating, and deleting forums and posts.

## Key Features
- User authentication system
- Forum creation and management
- Post creation and management
- Rich text editor functionality (tiptap-editor)
- Server-side and client-side API handling

## Technology Stack
- Frontend: Next.js with TypeScript
- Database: Prisma ORM
- Styling: CSS modules (globals.css)
- State Management: Context API (auth-provider)
- Deployment: Docker support included
